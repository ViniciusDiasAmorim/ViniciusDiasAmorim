# Vinícius Dias Amorim de Matos

Desenvolvedor .NET em São Paulo. Há cerca de 3 anos atuo no mesmo produto em produção: um **backoffice de gestão de recursos em nuvem e financeiro**.

Comecei em eletrônica e migrei para desenvolvimento em 2022. Desde então trabalho com sistemas legados críticos — o tipo de código que roda todo dia e não pode parar. Hoje divido o tempo entre sustentar esse legado e modernizá-lo para .NET 8.

**Backend**
- C#, VB.NET, .NET Framework e .NET 8 — legado e moderno convivendo
- Windows Forms na aplicação de back-office
- Regras de negócio de domínio financeiro e de gestão de infraestrutura

**Banco de dados**
- SQL Server no dia a dia: procedures, CTEs, índices e otimização de queries críticas
- Scripts de deduplicação e relatórios de auditoria

**Confiabilidade**
- Automação de testes de UI construída do zero: FlaUI + NUnit, Page Objects
- Testes unitários com xUnit
- Build com assinatura de código (chaves em HSM e timestamp)

**Integrações**
- AWS e OCI via SDK: expansão de disco, agendamentos em massa de backup/start/stop, templates de regras de firewall e rastreamento de criação de instâncias
- SAP Business One

**Processo**
- Git (branch, rebase, resolução de conflitos), Bitbucket, Jira, Conventional Commits

## 📌 Projeto em destaque

### [call-service](https://github.com/ViniciusDiasAmorim/call-service) — sistema de chamados

Projeto pessoal onde exercito, fora do trabalho, o que o legado não me dá espaço para usar:

- **ASP.NET Core** e **Entity Framework Core** com migrations reais
- **ASP.NET Identity + JWT** com refresh token, RBAC por policies e BCrypt
- **Repository + Unit of Work**, camada de serviços com interfaces, DTOs e FluentValidation
- **PostgreSQL**, **Docker Compose** e **CI/CD no GitHub Actions**
- Regras de negócio de verdade, como limite de chamados ativos por técnico
